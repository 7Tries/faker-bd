# Реестр пользователей (Flask + PostgreSQL + Docker + Faker)

Веб-приложение с базой данных PostgreSQL в Docker, автоматически генерирующее 1000 записей разделенных на две таблицы: публичную (`public_users`) и закрытую с паспортными данными (`sensitive_users`).

---

## Предварительные требования
Убедитесь, что у вас запущен **Docker Desktop**.

---

## Способ 1. Полный запуск через Docker Compose (БД + Сайт в Docker)

1. Откройте терминал (командную строку) в папке с проектом.
2. Запустите сборку и контейнеры командой:
   ```bash
   docker compose up -d --build
   ```
3. Откройте сайт в браузере:
   ```text
   [http://127.0.0.1:5000](http://127.0.0.1:5000)
   ```

---

## Способ 2. Запуск БД в Docker, а сайта локально через Python

Если вы хотите запустить в Docker только базу данных PostgreSQL, а код запускать напрямую из VS Code / терминала:

1. Запустите только контейнер базы данных:
   ```bash
   docker compose up -d db
   ```
2. Установите зависимости локально (если активен SOCKS-прокси/VPN, сначала сбросьте переменные прокси):
   ```cmd
   set HTTP_PROXY=
   set HTTPS_PROXY=
   set ALL_PROXY=
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python app.py
   ```
4. Откройте сайт в браузере:
   ```text
   [http://127.0.0.1:5000](http://127.0.0.1:5000)
   ```

## Подключение к БД через DBeaver

1. Откройте **DBeaver**.
2. Нажмите **База данных** -> **Новое соединение** (или иконку розетки с плюсом в левом верхнем углу).
3. Выберите **PostgreSQL** и нажмите **Далее**.
4. На вкладке **Главное (Main)** введите следующие данные:

| Поле в DBeaver | Значение для ввода |
| :--- | :--- |
| **Хост (Host)** | `localhost` |
| **Порт (Port)** | `5432` |
| **База данных (Database)** | `users_db` |
| **Пользователь (Username)** | `admin` |
| **Пароль (Password)** | `secretpassword` |

5. Нажмите кнопку **Тест соединения... (Test Connection...)** внизу слева (если DBeaver предложит скачать драйвер PostgreSQL — нажмите **Скачать / Download**).
6. Нажмите **Готово (Finish)**.
7. В левом меню раскройте: `users_db` -> `Схемы (Schemas)` -> `public` -> `Таблицы (Tables)` -> внутри будут таблицы **`public_users`** и **`sensitive_users`**.

## Полезные команды для управления Docker

* **Посмотреть статус работающих контейнеров:**
  ```bash
  docker compose ps
  ```
* **Посмотреть логи генерации данных и работы сервера:**
  ```bash
  docker compose logs -f
  ```
* **Остановить контейнеры (с сохранением данных в БД):**
  ```bash
  docker compose down
  ```
* **Остановить контейнеры и полностью очистить БД (чтобы сгенерировать 1000 новых записей с нуля):**
  ```bash
  docker compose down -v
  ```
